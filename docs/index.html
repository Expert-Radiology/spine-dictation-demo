THE WORKING PILOT

Where templates
and blurbs fit.

1 Start from the chosen template

The pilot uses the matching approved spine MRI template. Dictated findings replace conflicting defaults; unrelated template statements stay. Missing dictated levels are added.

2 Expand the blurb where it belongs

A blurb is a name for a saved passage. When it is mentioned at L5-S1, its text belongs at L5-S1 and in any additional section its rule specifies. Unclear names or missing details are flagged.

3 Review before signing

The goal is less manual transcription. The draft still goes through MT review and the radiologist’s review and signature. This demo cannot issue or sign a clinical report.

What this demonstration does—and what is still being developed

The underlying pilot converts recorded audio into text, then proposes changes to an approved template. The comparison above uses fictional text and preset edits rendered by the same template-rendering module. The example blurbs are teaching examples, not a copy of the approved library.

The latest protected pilot produced four new drafts. All four remain held for unresolved content. Blurb interpretation, level placement and unclear audio need further work. We compare drafts with signed reports to find errors; the generator never sees those signed targets. No model weights have been trained, and no BetterPACS integration is deployed.

This page has no upload field, microphone access, analytics or model connection. Only fictional bundled media and text are loaded. Public demo material must never contain patient data.
